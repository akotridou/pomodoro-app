# 🍅 Pomodoro App

A simple and elegant Pomodoro timer built with HTML, CSS and JavaScript.

The app provides a focused countdown timer designed to help with studying, working, and maintaining productive work sessions.

## ✨ Features

- ⏱️ 25-minute Pomodoro countdown
- ▶️ Start the timer
- ⏸️ Stop the timer
- 🔄 Reset the timer
- 🔢 Dynamic minute and second display
- 🚫 Prevents multiple timers from running at the same time
- 💬 Displays a message when the timer reaches zero
- ✨ Motivational message and quote
- 📱 Responsive and clean interface

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Event Listeners
- `setInterval()`
- `clearInterval()`

## 🎯 How It Works

The timer starts at 25 minutes.

When the user presses **Start**, JavaScript begins a one-second interval that decreases the remaining time.

The **Stop** button pauses the countdown, while **Reset** returns the timer to the default 25-minute duration.

When the countdown reaches zero, the user is notified that the time is up.
